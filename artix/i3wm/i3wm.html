Artix Linux x240 Comprehensive Guide

A strictly complete walkthrough with conditional sudoer power permissions.

1. Physical Preparation & Boot

1. Plugin Ethernet cable.

2. Boot from Ventoy.

3. Login from artix user.

sudo su

2. Internet Connection (Wi-Fi)

1. Check name of wifi:

ip a

2. Unblock and bring the interface up:

rfkill unblock wifi
ip link set wlan0 up

3. Enter the Connman utility:

connmanctl

4. Inside connmanctl, run these commands in order:

scan wifi
services
agent on
connect wifi_(tab)_(input first 3 characters)(tab)
# Enter passphrase if prompted
quit

5. Verify connectivity and clear screen:

ip a
ping -c 50 8.8.8.8
clear

3. Disk Partitioning

1. Check device name (usually /dev/sda):

lsblk

2. Setup partitions via cfdisk:

sudo cfdisk

3. Format the partitions:

mkfs.fat -F32 /dev/sda1
mkfs.ext4 /dev/sda3

4. Mount and check status:

mount /dev/sda3 /mnt
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi
lsblk

4. Base System

1. Install base system and drivers:

basestrap /mnt base base-devel runit elogind-runit linux linux-firmware nano intel-ucode

2. Setup filesystems:

fstabgen -U /mnt >> /mnt/etc/fstab
cat /mnt/etc/fstab
clear
artix-chroot /mnt

5. ISO Configuration (Inside Chroot)

5.1 Swap File

1. Create 2G swap file:

dd if=/dev/zero of=/swapfile bs=1G count=2 status=progress
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
Add entry to fstab: 
nano /etc/fstab
/swapfile none swap default 0 0

5.2 Time and Locale

1. Set Timezone:

ln -sf /usr/share/zoneinfo/Asia/Manila /etc/localtime
hwclock --systohc
Uncomment en_PH.UTF-8 UTF-8 in locale.gen: 
nano /etc/locale.gen
en_PH.UTF-8 UTF-8

2. Generate locale and set language:

locale-gen
nano /etc/locale.conf
LANG=en_PH.UTF-8

5.3 Hostname and Hosts

Set machine name to x240: 
nano /etc/hostname
x240
Add entry to the last line: 
nano /etc/hosts
127.0.1.1 x240.localdomain x240

3. Set root password:

passwd

7. Bootloader & User Account

1. Install and update GRUB:

grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg

2. Create user x240 and set password:

useradd -mG wheel x240
passwd x240
Open the sudoers file to grant wheel permissions: 
VISUAL=nano visudo

Locate the wheel group line and uncomment it:

%wheel ALL=(ALL:ALL) ALL
Add the NOPASSWD power commands at the very end of the file: 
# Custom power commands for x240
x240 ALL=(ALL) NOPASSWD: /sbin/shutdown, /sbin/poweroff, /sbin/reboot

3. Finalize and reboot:

exit
umount -R /mnt
reboot

8. Post-Reboot Service Setup

1. Login as user and enter sudo su.

2. Check entries in service directory:

cd /run/runit/service
ls
cd
clear

3. Enable network and wifi:

ln -s /etc/runit/sv/NetworkManager /run/runit/service/NetworkManager
nmtui
ping -c 50 8.8.8.8

4. Unplug LAN Ethernet cable if ping is successful.

5. Enable other services and video driver:

ln -s /etc/runit/sv/bluetoothd /run/runit/service/bluetoothd
ln -s /etc/runit/sv/cupsd /run/runit/service/cupsd
ln -s /etc/runit/sv/dbus /etc/runit/runsvdir/default/

9. Audio Setup

1. Install bridges and engines:

sudo pacman -S pipewire pipewire-pulse pipewire-alsa pipewire-jack wireplumber alsa-utils
IMPORTANT: THIS PACKAGES SHOULD HAVE ALREADY BEEN INSTALLED EARLIER. When prompted to remove jack2 in favor of pipewire-jack, choose 'y'.

2. Configure realtime priority:

sudo groupadd realtime
sudo usermod -aG audio,realtime,video,input,storage,optical x240
sudo mkdir -p /etc/security/limits.d
sudo nano /etc/security/limits.d/99-realtime.conf
@realtime           -       rtprio          98
@realtime           -       memlock         unlimited

3. Unmute the card via Alsamixer:

sudo alsactl init
Open alsamixer -c 1. Press M on Master, Headphone, and Speaker until they show 'OO'. Set Auto-Mute to Disabled.

10. Trash Setup

1. Enable GVFS/D-Bus:

sudo mkdir -p /var/service
sudo ln -s /etc/runit/sv/dbus /var/service/
sudo sv status dbus
sudo reboot

11. Setting up i3wm Launch

11.1 Initial Reboot

1. Reboot the system:

sudo reboot

2. Login as the x240 user. Do not launch i3 through startx yet.

11.2 Mount Extended Partition

1. Create mount point and set permissions:

sudo mkdir -p /mnt/Extended
sudo chown x240:x240 /mnt/Extended
sudo chmod 755 /mnt/Extended

2. Edit the filesystem table:

sudo nano /etc/fstab
Add the following entry: 
# /dev/sda4
LABEL=Extended /mnt/Extended ext4 defaults,errors=remount-ro,user,exec 0 2

3. Mount the partition and reboot:

sudo mount -a
sudo reboot

11.3 Copy Dotfiles

1. Login (do not launch startx) and copy hidden configuration files from the extended partition:

cp -r /mnt/Extended/"Artix dotfiles"/.* /home/x240/

11.4 Scripts and Resources

1. Merge X resources and make the audio script executable:

xrdb -merge ~/.Xresources
chmod +x ~/.start-pipewire.sh

12. Edit GRUB

1. Open the GRUB configuration from the TTY:

sudo nano /etc/default/grub

2. Apply the following changes:

  • Remove quiet from GRUB_CMDLINE_LINUX_DEFAULT
  • Uncomment GRUB_TERMINAL_OUTPUT=console
  • Set GRUB_GFXMODE=1366x768x32,1024x768,auto

3. Update the bootloader:

sudo grub-mkconfig -o /boot/grub/grub.cfg

13. Reboot into i3wm

sudo reboot

This should prompt you to i3wm automatically after logging in. Proceed to set the i3 config when prompted.

14. Copy i3 Config Files

1. Copy specific i3 settings:

cp -r /mnt/Extended/"Artix dotfiles"/i3/* /home/x240/.config/i3/

2. Refresh i3 and reboot:

Press Shift+Mod+R to reload, then:

sudo reboot

15. Add Repositories

1. Login to i3 and open pacman config:

sudo nano /etc/pacman.conf
Add these lines to the very end of the file: 
# Artix Linux Repositories
[universe]
Server = https://universe.artixlinux.org/$arch
Server = https://mirror1.artixlinux.org/universe/$arch
Server = https://mirror.pascalpuffke.de/artix-universe/$arch

# Arch Linux repositories
[extra]
Include = /etc/pacman.d/mirrorlist-arch

[multilib]
Include = /etc/pacman.d/mirrorlist-arch

2. Initialize keys and sync:

sudo pacman-key --init
sudo pacman-key --populate artix
sudo pacman-key --populate archlinux
sudo pacman -Syy && sudo pacman -Syu

16. Set to Dark Mode

1. GTK Settings: Launch lxappearance via rofi.

  • Widgets: Adwaita-dark
  • Icon Themes: Papirus-Dark

2. QT Settings: Launch qt5ct and qt6ct via rofi.

  • Style: Fusion
  • Color Scheme: darker

17. Fix Audio Issues

1. Create Wireplumber configuration:

mkdir -p ~/.config/wireplumber/wireplumber.conf.d/
nano ~/.config/wireplumber/wireplumber.conf.d/50-alsa-config.conf
monitor.alsa.rules = [
  {
    matches = [
      {
        node.name = "~alsa_output.pci.*.analog-stereo"
      }
    ]
    actions = {
      update-props = {
        priority.driver = 1000
        priority.session = 1000
      }
    }
  }
]

2. Restart audio services:

killall -9 pipewire pipewire-pulse wireplumber
rm -rf ~/.local/state/pipewire
~/.start-pipewire.sh

3. Verify the sink:

pactl list sinks short

The issue is resolved if you see a line starting with alsa_output.pci...analog-stereo.

If video plays without sound: Ensure earphones are plugged in and pavucontrol is not muted. If issues persist, run: 
pactl set-sink-mute @DEFAULT_SINK@ 0
pactl set-sink-volume @DEFAULT_SINK@ 70%
